# Movie Recommender System

This project is a content-based and GNN-based movie recommender system built using Python, Scikit-learn, TensorFlow, and PyTorch Geometric.

## 🔍 Datasets Used
- TMDB 5000 Movies Dataset
- TMDB 5000 Credits Dataset
- @info : https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

## 📌 Features
- TF-IDF Vectorizer based recommendations
- Autoencoder-based feature compression
- GNN (Graph Neural Network) based recommendations
- Cosine similarity for similarity scores
- Visualization using t-SNE and NetworkX

## 🚀 Technologies
- Python, Pandas, NumPy
- Scikit-learn, TensorFlow, PyTorch
- PyTorch Geometric, Matplotlib
